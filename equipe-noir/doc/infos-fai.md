# Informations FAI pour l'accès à Internet

## Informations à donner aux autres équipes

### Port physique R1 : WLAN
C'est le port physique du routeur 1 auquel nous allons nous brancher pour délivrer une connexion Internet dans chaque équipe.

### IP Serveur DNS récursif :
C'est l'adresse du serveur DNS récursif du FAI fournit avec la connexion Internet qui permet de résoudre tous les noms du DNS standard et ceux du TLD iut. 
### Plages d'IP publiques par équipe : 
- Équipe Blanc : 192.168.1.0
- Équipe Rouge : 192.168.2.0
- Équipe Vert : 192.168.3.0
- Équipe Noir : 192.168.4.0

### IP du R1 du FAI : 
L'IP du routeur 1 du FAI va servir de passerelle par défaut pour toutes les autres équipes.
